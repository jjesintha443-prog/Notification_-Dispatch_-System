# Notification Dispatch System

A Java-based Notification Dispatch System that demonstrates the Observer Design Pattern. The system manages notifications using a queue and dispatches them to multiple observers such as Email, SMS, and Push Notification services.

## Features
- Observer Design Pattern implementation
- Notification queue management
- Multiple notification channels (Email, SMS, Push)
- Modular and object-oriented Java code
- Easy to extend with additional notification types

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- Observer Design Pattern

## Project Structure
- Main.java
- Notification.java
- Observer.java
- EmailObserver.java
- SMSObserver.java
- PushObserver.java
- NotificationService.java
